# Behind-the-Numbers
STAT 442 Shiny App - Exploring 2024 Fatal Car Accidents

### Interactive Shiny App:
https://maddisononken.shinyapps.io/behind-the-numbers/

### Project Overview
Behind the Numbers is an interactive Shiny applicaiton that explores fatal accidents in the United States usint 2024 data from the Fatality Analysis Reporting System (FARS).

The goal of this project is to explore patterns in fatal crashes and learn more about the people involved and the circumstances surrounding these crashes.

### App Features
The app is organized into three sections:
1. Overview
   - Total number of fatal crashes
   - Total fatalities
   - Total people involved
   - Fatal crashes by month
3. People Involved
   - Age distribution
   - People by sex
   - Person type (drivers, passengers, pedestrians, etc.)
   - Reported restraint use
4. Crash Circumstances
  - Fatal crashes by state
  - Rural vs urban locations
  - Day of the week
  - Time of day
  - Speed-related factors
  - Driver distraction

### Files
- app.R - Contains the code for the Shiny application
- fars_data.rds - Contains the cleaned FARS data used in the application.
